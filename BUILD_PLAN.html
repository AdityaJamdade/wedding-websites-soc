01 — Overview

The Top-Down Strategy

Build the crown jewel first. Everything else becomes a deliberate simplification of what came before — not a build-up from scratch, but a disciplined peel-back of the highest tier.

01

Build Bespoke First

Bespoke is the reference implementation. Every feature that exists in any lower tier was first designed and built here. Nothing is invented for a lower tier that wasn't already in Bespoke.

02

Cascade Down

Each tier is Bespoke with things removed — not Essential with things added. This means every tier shares a common design DNA. Lower tiers feel like "simplified luxury," not "budget alternatives."

03

Template = Scale

Below Bespoke, every tier is a configurable template. New clients are onboarded in hours, not days. The engineering investment is already done — revenue is pure margin.

04

Premium Anchoring

Bespoke and Luxe are priced to anchor perception. They make Prestige look accessible, Signature look like a bargain, and Essential look like an entry point. The premium tier exists partly to sell the mid tiers.

05

Spectacular Demos

Every tier needs a jaw-dropping demo client. The demo IS the sales pitch. Before building features, plan and build the demo — it should make people feel something.

06

Client Turnaround = Moat

The goal is to onboard a new client in under 2 hours per tier (1–3 below Bespoke). Speed of delivery at quality is the defensible advantage. The template system makes this possible.

Current state audit: Essential and Signature are production-ready in v2.0. Prestige is production-ready in v3.0 (11 sections, video hero, 3 exclusive styles, 7 premium presets). Luxe (was "Elite") and Bespoke are both unbuilt. The entire revenue gap to $100k/month lives in building these two tiers and marketing all five.

06 — Technical Architecture

Stack Decisions

Each tier uses the right level of technology. Bespoke gets everything. Each tier below gets a simplified stack. No over-engineering on lower tiers — keep them fast and onboard-able.

Bespoke — Framework

Next.js 14 (App Router)

Multi-page architecture. Server components for performance. API routes for RSVP dashboard. Vercel deployment, edge functions for auth.

Bespoke — Backend

Supabase

PostgreSQL for RSVPs, guestbook, guest list. Row-level security per couple. Realtime subscriptions for dashboard live updates. Auth for couple login.

Bespoke — Animations

GSAP + Three.js

ScrollTrigger for scroll-driven animations. Three.js for 3D parallax hero scenes. Custom canvas particle engine for petals/stars. Framer Motion for UI micro-interactions.

Bespoke — Communications

Resend + Twilio

Resend for transactional emails (invitations, RSVP confirmations). Twilio WhatsApp Business API for RSVP push notifications to the couple.

Bespoke — AI

Claude API (Anthropic)

Story generation from couple's prompts. Caption writing. FAQ generation. Invoked via Next.js API route with structured prompts. Haiku model for speed, Sonnet for quality.

Bespoke — Media

Cloudinary

Image optimisation (auto WebP, responsive sizing). Video hosting for hero backgrounds. Guestbook photo uploads. CDN delivery worldwide.

Luxe + Prestige — Framework

React + Vite

Same codebase pattern as current Prestige v3.0. CLIENT= env var drives config. Fast build, simple deployment. Single-page app. Works perfectly for template-based delivery.

Luxe — Backend (light)

Supabase (simple)

Single table for guestbook messages. Single table for RSVP responses. Anon key in client — no auth needed for guests to submit. Couple gets read-only dashboard URL.

Luxe — Particles

Custom Canvas Engine

Lightweight vanilla JS canvas-based particle system ported from Bespoke. No heavy library dependency. Four presets: petals, stars, fireflies, snow. Toggle in appsettings.js.

Prestige & Below — Forms

Formspree

Zero-backend RSVP and music request forms. No infrastructure to manage. Reliable, fast, free tier covers most clients. Results emailed to couple directly.

All Tiers — Hosting

Vercel

Single Vercel account hosts all client sites. Per-project deployments. Edge CDN. Free tier covers Essential/Signature. Pro plan (~$20/mo) covers unlimited Prestige/Luxe sites.

All Tiers — Payments

Stripe

Payment links per tier (no complex checkout flow needed). 50% upfront, 50% on delivery. Stripe handles invoicing. Minimal setup, professional experience.

The client config convention stays: For Luxe, Prestige, Signature, and Essential — every client is a folder with an appsettings.js. Run with CLIENT=client-name npm run dev. Deploy with CLIENT=client-name npm run build. The system that makes the business scalable is already designed — we just extend it upward.

Pricing Rationale

Bespoke at $5k–$15k

Custom builds take 40–60 hours. At $8k average, that's ~$130–200/hr — competitive for a premium boutique service. The RSVP dashboard, AI content, and custom animations justify the ceiling. Clients who want this have the budget.

Luxe at $1,997

Under $2,000 is psychologically important. The price clears in minutes against the cost of a florist or photographer. Luxe includes password protection, a domain, particles, a guestbook, and a mini dashboard — genuinely worth far more than $2k to the couple.

Prestige at $797

The single-page luxury tier. Priced to be aspirational but clearly accessible. Video hero + exclusive design styles + 11 sections is a genuine premium product. The ~$800 price point is far below wedding photography — an easy yes for engaged couples.

Signature at $397

11 sections, countdown, full design library. More features than any competitor at this price. Designed to be the "obvious upgrade" from Essential when clients see the side-by-side. Upsell rate from Essential → Signature should be high.

08 — Client Acquisition

How We Get to 77 Clients / Month

The product sells itself when the demos are spectacular. The strategy is to let the demos do the work — and distribute them everywhere couples look when planning a wedding.

Highest Priority

📸 Instagram & Pinterest Reels

Post screen-capture videos of each tier's demo. The particle animations, video hero, and 3D effects are inherently scroll-stopping content. "This is a wedding website" hooks are proven to perform. Target: 3 posts/week per tier on launch.

Highest Priority

🌐 Live Demo Links

Every tier has a publicly shareable demo URL. Couples share it themselves — it's word of mouth built into the product. "Look what we found for our wedding website" spreads faster than any ad. The demos must be jaw-dropping.

Highest Priority

💬 Wedding Facebook Groups

Target groups like "Brides of [City] 2025/2026/2027." Post demos with a simple "made this for a couple last week, happy to take on more." These groups have hundreds of thousands of engaged couples actively seeking recommendations.

Medium Priority

📋 Wedding Directories

Submit to The Knot, WeddingWire, Hitched (UK), WedMeGood (India), Easy Weddings (Australia). Free listings available. These drive high-intent searches from couples actively planning. Takes 1–2 weeks to get listed.

Medium Priority

🤝 Wedding Photographer Partnerships

Offer photographers a referral fee ($50–100/client) to recommend the service. They photograph hundreds of couples a year — they need a recommendation for wedding websites, and they don't have one yet. A single photographer partner can send 20–30 clients/year.

Medium Priority

🔍 SEO Content

Target keywords: "luxury wedding website," "custom wedding website builder," "cinematic wedding website," "wedding website with RSVP dashboard." Long-tail content takes 3–6 months to rank but compounds over time. Start writing now.

Medium Priority

🎁 Referral Programme

Give every client a referral link. If they refer a friend: $50 credit on a future update, or the friend gets a discount. Couples talk to other couples at events — the referral flywheel is strong in this market.

Supporting

✉️ Email Sequence

Capture leads on the marketing site (free "wedding website checklist" lead magnet). 5-email nurture sequence: what's possible → demo showcase → tier comparison → testimonials → offer. Automated via MailerLite or Loops.

Supporting

🎯 Pinterest SEO

Screenshots of each tier's demo pinned to "wedding website inspiration" boards. Pinterest is a pull platform — couples searching for inspiration will find the demos. Low effort, high intent traffic over time.

The distribution shortcut: At launch, email 20 wedding photographers in your target market. Tell them you build the most beautiful wedding websites they've ever seen, offer a demo link, and propose a referral arrangement. Converting 5 of those 20 into recurring referral partners is worth 100+ clients/year at zero acquisition cost.
09 — The Rules

What We Never Compromise On

These are the non-negotiables. Deviate from these and the business becomes a commodity. Hold them and it stays a premium, word-of-mouth driven operation.

01

The Demo Must Be Jaw-Dropping

Every tier needs a demo that makes people stop scrolling and say "wait, that's a wedding website?" If the demo doesn't do that, don't launch the tier yet. The demo is the product.

02

Onboarding Time is Sacred

Essential: under 1 hour. Signature: 1–2 hours. Prestige: 2–4 hours. Luxe: 4–6 hours. Bespoke: 5–7 days. Any process that takes longer than this needs to be fixed before scaling.

03

Never Touch the Template for a Client

Every client customisation lives in appsettings.js (for template tiers). The template is never modified. This is the only way the business stays scalable. Bespoke is the only exception.

04

Every Tier Must Justify Its Price Visually

Prestige should look obviously different from Signature. Luxe should look obviously different from Prestige. Bespoke should look like it cost what it costs. Visual differentiation is how clients choose to upgrade.

05

Bespoke Ships First

The anchor tier is live before we market heavily. Having a $15,000 service on offer makes the $800 Prestige tier look like a deal. The price anchor is as important as the product itself.

06

Cascade is Strictly Downward

No feature is introduced in a lower tier that doesn't exist in all tiers above. If we build password protection for Luxe, it must also exist in Bespoke. This keeps the architecture coherent and the upgrade path compelling.

Build the best first. Then cascade down.
